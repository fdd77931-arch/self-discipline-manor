    Portfolio Case

    作品集说明

    这个项目的重点不是把功能做多，而是证明“自律行为 - 即时奖励 - 庄园建设 - 公益贡献 - 再行动”的闭环成立。 首屏负责让人直接体验，下方负责说明产品思考。

    01

    用户痛点

    传统打卡工具反馈弱、成长不可见，用户完成动作后很难感受到“今天的努力改变了什么”。

    02

    产品机制

    把打卡转化为金币、经验、庄园装饰和公益能量，让抽象坚持同时产生个人成长和社会价值。

    03

    MVP 取舍

    第一版保留打卡、奖励、庄园、公益项目池、商店和 AI 反馈。公益捐赠先做模拟，不接真实支付。

    04

    指标意识

    后续可关注首次打卡率、次日留存、公益能量投入率、项目偏好分布和商店购买转化率。

    和 Coze 原型的关系： 当前仓库里的 Coze/Python Agent 已有打卡、金币、等级、商店和自定义习惯工具。 这个 HTML Demo 先用本地状态模拟核心体验，后续可以接入 Agent HTTP 接口，让 AI 管家支持自然语言操作。
