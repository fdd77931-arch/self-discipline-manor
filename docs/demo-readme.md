# 自律庄园 HTML Demo

这是「自律庄园」作品集项目的可交互静态页面。它把现有 Coze Agent 原型中的打卡、金币、等级、商店购买能力，升级为“自律成长 × 公益贡献”的无需后端 Demo。

## 如何打开

直接用浏览器打开：

```text
portfolio/self-discipline-manor/index.html
```

页面会使用浏览器本地存储保存演示状态。可以点击页面右上方的「重置今日」重新演示当天打卡，也可以点击「清空演示」回到初始状态。

## Demo 包含

- 今日打卡：健身、冥想、阅读、学习、早睡、日记。
- 成长反馈：金币、公益能量、等级、经验、连续天数、今日完成进度。
- 公益项目池：将打卡获得的公益能量投入动物救助、困境助学、灾区援助、环保植树和医疗援助等方向，模拟公益贡献闭环。
- 庄园可视化：购买后的装饰会出现在庄园区域。
- 自由摆放：购买后的物品可以在所属场景内拖动，坐标会保存在浏览器本地。
- 场景进出：点击庭院房门进入小屋，点击室内房门回到庭院。
- 房屋升级：用金币升级房子，外观和空间感会随等级变化。
- 新手引导：用 4 步任务帮助体验者走完打卡、公益投入、购买、摆放的核心路径。
- 数据闭环：记录本地演示行为，展示核心路径完成率、打卡次数、公益投入、商店购买、摆放保存和房屋升级次数。
- 商店系统：根据金币和库存显示可购买、不可购买、已拥有。
- AI 管家反馈：每次打卡或购买后给出结果解释和下一步建议。
- 作品说明：页面下方展示用户痛点、产品机制、MVP 取舍和指标意识。

## 和 Coze 原型的关系

当前 HTML Demo 先用本地状态模拟核心体验，方便放进 GitHub Pages 或作品集页面。仓库中的 Coze/Python 项目已经包含 Agent、工具、数据库模型等后端能力，后续可以将页面操作接入 HTTP 接口，让 AI 管家支持自然语言打卡、购买和自定义习惯。

公益模块当前只模拟能量投入和项目进度，不涉及真实收款或捐赠承诺。真实落地版本需要接入合规公益机构、品牌配捐、公开凭证和可追踪记录。
